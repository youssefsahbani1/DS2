# Gestion des tâches (Python)

Application console simple pour gérer des tâches quotidiennes.
Projet de la matière « Outils collaboratifs avec Git / GitHub » (Licence 1, S1).

## Fonctionnalités
- Ajouter une tâche (titre vide refusé)
- Afficher toutes les tâches numérotées (message si la liste est vide)
- Rechercher une tâche par mot-clé
-- Supprimer une tâche par son numéro
- Quitter (toute autre option affiche une erreur)

## Étapes réalisées
1. Création du programme `main.py` (menu, ajout, affichage, recherche)
2. Rédaction du `README.md`
3. Publication sur GitHub avec `git push`

## Exécution
1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir `main.py`.
3. Cliquer sur le bouton **Run Python File** (▶) en haut à droite.
4. Utiliser le menu dans le terminal.
